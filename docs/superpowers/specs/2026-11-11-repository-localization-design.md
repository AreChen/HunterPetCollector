# 仓库规范与多语言设计

## 目标与约束

将现有 Hunter Pet Collector 整理为公开 GitHub 仓库，并支持多语言。继续在现有游戏插件目录开发，以便通过游戏内重载测试。保持插件目录名、存档变量、两个客户端版本和现有功能兼容。

## 方案

采用独立语言文件：默认英文，简体中文客户端加载中文翻译；缺失条目回退英文。另一种方案是在业务代码中分别写各种语言，短期改动较少，但后续增加语言和维护翻译成本较高。

## 设计

- 在两个 TOC 中按正确顺序加载本地化文件，业务代码通过共享语言表读取展示文字；不翻译命令、协议标识、数据键或其他影响兼容性的内部标识。
- 翻译界面、提示、选项和聊天反馈等插件自有文本；游戏或数据来源提供的名称在可用时使用游戏本地化，否则保留原文。格式占位符和颜色代码保持兼容。
- 建立必要的仓库文档、忽略规则和适合插件的自动检查；保留 GPLv3 和现有第三方数据来源说明。
- README 明确说明本项目基于他人作品继续开发，保留原作者和上游归属，记录本项目修改。上游名称、地址、版本及授权以可核实信息为准，不推测或冒充原作者。
- 本地初始化 Git 并创建公开 GitHub 仓库；不移动或替换当前插件目录。公开发布前核实上游插件及其授权来源。
- 验证两个 TOC 的加载文件、Lua 语法、本地化缺项及格式占位符，并说明游戏内验证仍需实际客户端。

## 范围之外

不改变玩法、存档格式或通讯协议，不承诺其他语言已完成翻译。不要将无法确认的数据授权描述为已核实。

## 主界面与设置（新增需求，待确认）

- 修复主窗口顶部统计栏、操作按钮、标签和关闭按钮的重叠，保证布局留出间距。
- 保留深色背景和猎人绿色，统一主窗口、面板及按钮的圆角视觉样式。
- 将插件设置整合为主窗口内的可滚动设置页，通过齿轮和 `/hpc options` 打开；沿用已有设置项、即时生效逻辑及存档。
- 设置内容过长时滚动，不改变战斗中受保护操作的行为。验证不同窗口宽度、语言文本和两种客户端加载路径。
